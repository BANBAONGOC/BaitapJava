# Bai tap Java - Mang so nguyen

## Noi dung
- `Bai1.java`: Nhap n so nguyen vao mang va tinh tong.
- `Bai2.java`: Viet ham nhan hai mang va tra ve mang tong theo tung vi tri. Neu mot mang ngan hon, phan tu thieu duoc xem la 0.
- `Bai3.java`: Nhap mot dong cac so nguyen cach nhau boi dau cach, in so phan tu va tong.

## Yeu cau
- Da cai dat JDK.
- Co the dung VS Code va Extension Pack for Java.

## Cach chay
Mo Terminal trong thu muc nay va chay mot bai tai mot thoi diem:

```bash
javac Bai1.java
java Bai1
```

```bash
javac Bai2.java
java Bai2
```

```bash
javac Bai3.java
java Bai3
```

## Vi du Bai3
Input:
```text
3 4 5 33 554 67 23 6 8 5
```

Output:
```text
So phan tu: 10
Tong: 708
```
